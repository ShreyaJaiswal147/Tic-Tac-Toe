Tic Tac Toe Game (Python Tkinter)
Description

This is a simple Tic Tac Toe game built in Python using the Tkinter GUI library.
It allows two players to play on the same computer. The game automatically detects wins and draws, and resets the board for a new game.

Features

🎮 Two-player game (X vs O)

🏆 Win detection

🤝 Draw detection

🔄 Automatic board reset after game ends

🖥️ Simple GUI interface using Tkinter

Requirements

Python 3.x

Tkinter library (comes pre-installed with Python on most systems)

Installation

Clone or download this repository.

Make sure Python 3 is installed.

No additional libraries are needed since Tkinter comes with Python.

How to Run

Open a terminal / command prompt in the project folder.

Run the following command:

python app.py

The game window will open. Click on the buttons to place your X or O.

Gameplay

Player X always goes first.

Click on any empty square to place your mark.

The game announces a winner or a draw automatically.

The board resets after each game.
